# Clear Water Pool Service (sample site)

A sample website I designed for Clear Water Pool Service, a pool cleaning and maintenance service in Arlington, TX. I put together sites like this to show local businesses what a modern, mobile-friendly web presence could look like for them before they commit to anything.

**Live preview:** https://preview-clear-water-pool-service.vercel.app

## Design

Navy and aqua to keep it clean and watery, with Bricolage Grotesque headlines. Weekly service plans and repairs are laid out so a homeowner can see what's covered at a glance.

## Stack

- Plain HTML and CSS in a single `index.html`, with no framework and no build step
- Responsive, mobile-first layout
- Google Fonts, plus photos from Unsplash (credited on the page)
- Hosted on Vercel

## Running it locally

Open `index.html` in a browser, or serve the folder with something like `npx serve .`

## Notes

- This is a sample site, not the business's official website, and it isn't affiliated with or published by Clear Water Pool Service.
- The contact form is for demo purposes only and doesn't send anything.
- Search engines are blocked for now (`robots.txt` and a `noindex` header in `vercel.json`) until the business decides whether it wants the site live.
